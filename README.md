# TON 26 Double-Q

The codes provided here correspond to the numerical simulations in our paper, "Double-Q: Achieving Best-of-Two-Worlds Performance of Constrained Online Convex Optimization," submitted to *IEEE Transactions on Networking (TON)*.

Each folder contains one experiment. Please enter the corresponding folder, run each algorithm file separately, and then run `draw.py` to generate the final figure.

## Experiments

- `Fixed`: online quadratic programming with fixed constraints.
- `TimeVarying`: online quadratic programming with time-varying constraints.
- `FraudDetection`: online fraud detection with a credit-card transaction dataset.
- `JobScheduling`: online network job scheduling with workload and cost traces.

See the `README.md` inside each folder for requirements, data files, and run commands.
